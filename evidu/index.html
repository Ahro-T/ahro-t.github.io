01 · Problem

한 명의 학생을 둘러싼
세 사람의 고민.

문제는 콘텐츠가 부족해서가 아닙니다. 학습 과정이 보이지 않고, 학습 데이터가 세 사람 사이에서 단절되어 있기 때문입니다.

01
“강의는 많은데, 지금 무엇을 공부해야 할지 모르겠어요.”

계획 수립, 진도 점검, 취약점 복습을 학생 개인의 의지에 의존합니다.

학생 · 비효율적 학습과 이탈
02
“학생이 많아질수록 각자의 상태를 제대로 보기 어렵습니다.”

학생별 진도와 오답을 수작업으로 확인하느라 실제 교육 개입에 쓸 시간이 줄어듭니다.

선생님 · 관리 비용과 개인화 한계
03
“아이가 제대로 공부하는지, 교육비가 효과적인지 알기 어렵습니다.”

학부모는 성적표가 나온 뒤에야 문제를 발견하고, 과정이 아닌 결과로만 판단합니다.

학습 정보의 단절입니다.

강의, 문제 풀이, 오답, 질문, 학습 시간은 각각 흩어져 있습니다. 데이터가 연결되지 않으니 학생은 다음 행동을 모르고, 선생님은 개입 시점을 놓치며, 학부모는 학습 과정을 보지 못합니다.

One Data.
Three Experiences.

  • 강의·문제·질문 상호작용
  • 선생님 개입과 이후 변화

03 · Agentic Architecture

계획하고, 추적하고,
필요한 순간에 가르칩니다.

세 Agent가 별도 기능으로 끝나는 것이 아니라 하나의 폐쇄형 학습 루프를 만듭니다.

Planner Agent
🗓️

목표, 시험 일정, 가용 시간, 최근 학습 기록을 바탕으로 계획을 만들고 실시간으로 수정합니다.

출력 · 오늘의 학습 계획 / 일정 재조정
Tracer Agent
📍

진도, 오답, 학습 시간, 개념 관계를 분석해 현재 이해도와 위험 신호를 추적합니다.

출력 · 취약 개념 / 개입 우선순위
Tutor Agent
💬

학생에게 필요한 시점에 문제, 힌트, 설명, 강의와 복습 콘텐츠를 제공합니다.

출력 · 설명 / 문제 / 콘텐츠 추천

→
Think학생 상태 판단
→
Act계획·콘텐츠 조정
→
Learn새 데이터로 개선

학생
2

Tutor Agent가 이해 점검 문제를 제시합니다.

학생
3

Tracer Agent가 오답과 취약 개념을 반영합니다.

개념 그래프에서 현재 숙련도와 연결된 선수 개념을 업데이트합니다.

학생·선생님
4

Planner Agent가 다음 계획을 수정합니다.

남은 시간과 목표를 고려해 복습과 다음 강의를 재배치합니다.

학생
5

선생님에게 개입 우선순위를 제공합니다.

직접 설명이 필요한 학생과 자동 복습으로 해결 가능한 학생을 구분합니다.

선생님
6

주간 변화가 학부모 리포트에 반영됩니다.

수행률, 성장, 취약점, 다음 계획을 이해하기 쉬운 문장으로 제공합니다.
